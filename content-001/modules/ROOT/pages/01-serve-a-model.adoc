= Module 1: Serve a Model
:navtitle: Serve a Model

== Objective

Pull the Red Hat AI Inference Server container image and serve an IBM Granite model on your CPU. By the end of this module, you will have a running inference endpoint on `localhost:8000`.

== Exercise 1: Pull and Run the Inference Server

The Red Hat AI Inference Server is a single container image. One command pulls it, starts it, downloads a model, and begins serving.

[source,bash,role="execute"]
----
podman run -d --name inference-server \
  -p 8000:8000 \
  -e MODEL_ID=ibm-granite/granite-3.2-2b-instruct \
  -e DTYPE=bfloat16 \
  registry.redhat.io/rhelai1/vllm-openai-ubi9:latest
----

This will:

. Pull the Red Hat AI Inference Server image (based on vLLM)
. Download the `ibm-granite/granite-3.2-2b-instruct` model (~4GB)
. Start serving the model on port 8000

NOTE: The model download takes a few minutes on first run. Subsequent starts use the cached weights.

== Exercise 2: Watch the Startup Logs

Follow the container logs to see the model load:

[source,bash,role="execute"]
----
podman logs -f inference-server
----

Wait until you see a message like:

[source]
----
INFO:     Uvicorn running on http://0.0.0.0:8000
----

That means the model is loaded and the server is ready. Press `Ctrl+C` to stop following logs.

[sidebar]
****
*What just happened:*

The inference server loaded a 2-billion-parameter language model into memory and started an OpenAI-compatible API server. The model weights are stored in bfloat16 precision, and every matrix operation uses whatever acceleration your CPU provides -- including Intel AMX on Xeon 6 processors.

This is the same serving engine (vLLM) used in production at scale. You are running it with one container command.
****

== Exercise 3: Verify the API

Check that the model is listed and the API is responding:

[source,bash,role="execute"]
----
curl -s http://localhost:8000/v1/models | jq .
----

You should see output showing the model ID `ibm-granite/granite-3.2-2b-instruct` in the model list.

[source,bash,role="execute"]
----
curl -s http://localhost:8000/health
----

A healthy server returns a `200` status.

== Exercise 4: Check for AMX (Optional)

If you are running on an Intel Xeon 6 or 4th/5th Gen Xeon Scalable processor, you have AMX acceleration:

[source,bash,role="execute"]
----
lscpu | grep -i amx
----

If AMX flags (`amx_bf16`, `amx_int8`, `amx_tile`) appear, your inference is hardware-accelerated. If they do not appear (older CPU or non-Intel), the model still works -- just without AMX acceleration.

== Verify

[%interactive]
* [ ] Inference server container is running

* [ ] `/v1/models` endpoint returns the Granite model

== Learning Outcomes

* The Red Hat AI Inference Server is a single container image -- no installation, no dependencies
* One `podman run` command serves a production-grade model
* The server exposes an OpenAI-compatible API on port 8000
* Intel AMX accelerates inference automatically when present -- no configuration needed

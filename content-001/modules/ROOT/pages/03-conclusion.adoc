== What You Just Proved

In 20 minutes, you:

* Pulled a production-grade AI inference server as a single container
* Served an open-weight model on your CPU — no GPU, no cloud, no license
* Called it with the same API that every major AI provider uses
* Classified text, extracted entities, and answered questions — from `curl`

The cost of everything you just did: zero per token. The model is open-weight (IBM Granite). The runtime is open-source (vLLM). The hardware is whatever x86 server you already own.

== Why This Matters for Your Business

[cols="2,3",options="header"]
|===
| Customer Question | Your Answer
| "Do we need GPUs to start with AI?" | No. You just ran a model on a CPU. GPUs matter at scale or for frontier reasoning — not for classification, extraction, or summarization.
| "What does it cost per token?" | Zero. Open-weight model on hardware you already own. Cloud APIs charge $0.01-0.06 per 1K tokens. This is free.
| "Is it the same quality as cloud APIs?" | For enterprise tasks (classification, NER, summarization), a 2-3B open model matches cloud API accuracy. You proved it in Exercise 2.
| "Can we switch models later?" | Yes. Same API, same container, different model. Change one environment variable.
| "Does it scale?" | That's what 101 covers. Same container, deployed on OpenShift with auto-scaling and model management.
|===

= AI on Hardware You Already Own
:navtitle: Welcome

_Serve an open-weight AI model from a single container on Intel Xeon._

== The Business Case

Every enterprise has x86 servers. Most sit at 20-30% CPU utilization. Those idle cores can serve AI models — classification, entity extraction, summarization — at zero incremental cost. No GPU purchase. No cloud API bill. No vendor lock-in.

This quickstart proves it. In 20 minutes, you will serve an open-weight AI model from a single container and call it with the same API that OpenAI, Anthropic, and every major provider uses. The difference: you own it, it runs on your hardware, and it costs nothing per token.

== What You'll Do

* Pull the Red Hat AI Inference Server container image
* Serve an IBM Granite model on your CPU — no GPU required
* Call the model using the standard OpenAI chat completions API
* Classify text, extract entities, and ask questions — all from `curl`
* Verify Intel AMX acceleration is contributing to the performance

== Prerequisites

[cols="2,3",options="header"]
|===
| Requirement | Details
| x86_64 Linux | RHEL, Fedora, Ubuntu, or WSL2 on Windows
| Podman or Docker | Any container runtime
| ~4GB free memory | For the 2B parameter model
| Internet access | To pull the container image (~2GB)
|===

No cluster. No cloud account. No GPU. No license key.

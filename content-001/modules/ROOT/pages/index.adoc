= Your First AI Inference — Hands-On Lab
:navtitle: Welcome

== The Big Idea

You can serve an AI model with a single container command. No cluster, no cloud, no GPU. Just a container image and a CPU.

The Red Hat AI Inference Server ships as a container image. Pull it, run it, call it.

== What You'll Do

In this lab you will pull the Red Hat AI Inference Server container image, serve an IBM Granite model on your CPU, and make inference calls using the OpenAI-compatible API.

No slides. No watching. You run the commands and see the results yourself.

== Learning Objectives

* Pull and run the Red Hat AI Inference Server container image
* Serve an IBM Granite model on a CPU -- no GPU required
* Call the model using the standard OpenAI chat completions API
* Classify text, extract entities, and ask questions -- all from `curl`
* Understand that the same API works at every scale: laptop, server, OpenShift

== What You Need

[cols="2,3",options="header"]
|===
| Requirement | Details
| Linux server | Any x86_64 machine with 8GB+ RAM
| Container runtime | Podman or Docker installed
| Internet access | To pull the container image and model weights
|===

That's it. No Kubernetes. No operator. No cloud account.

== The Episodic Series

This lab is the first stepping stone in a five-part series. Each level builds on the previous one:

[cols="1,3,3,1",options="header"]
|===
| Level | Title | What You'll Learn | Time
| *001* | *Your First AI Inference* | *Serve a model from a container on any Linux box* | *~20 min*
| 101 | Model Deployment | Deploy and call AI models on OpenShift | ~45 min
| 201 | Building an AI Agent | Wrap a model in tools and orchestration | ~45 min
| 301 | Multi-Agent AI at Scale | Route, optimize, and scale many agents across CPU and GPU | ~2 hrs
| 401 | Confidential AI | Protect inference with Intel TDX trusted execution | ~1 hr
| 501 | VMs + AI | Run AI alongside existing VM workloads | ~45 min
|===

Everything you learn here carries forward. The container image you run in 001 is the same inference server that RHOAI deploys in 101. The API you call here is the same API your agent calls in 201. Nothing changes but the scale.

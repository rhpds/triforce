# Publishing House intake — Intel Xeon 6 201

## Submission summary

**Title:** Intel Xeon 6 201: Building an AI Agent

**Format:** 45-minute, single-user hands-on lab

**Audience:** Intel and Red Hat technical sellers and solution architects

**Outcome:** The learner deploys a lightweight agent application on OpenShift,
connects it to three MCP tools, and generates an illustrative solution brief
using RACMaaS CPU inference on Intel Xeon 6.

**Infrastructure:** A tenant namespace on the shared
`ai-lab-xeon6-inference` cluster. The catalog provisions the OpenShift login and
a seven-day RACMaaS virtual key. The lab does not deploy a model server.

**Components:** Showroom, OpenShift, LangGraph agent, MCP JSON-RPC service,
web UI, and RACMaaS.

**Owner:** Jonathan Kershaw (`jkershaw@redhat.com`), RHDP

## Scope

Only this standalone lab is submitted. The quick-start items follow the
separate quick-start-to-lab review process. No event or production catalog
configuration is included in this intake.

## Security and data handling

- RACMaaS credentials are generated by the catalog and stored in an OpenShift
  Secret; no master key is assigned to the learner.
- Workloads run as non-root and drop Linux capabilities.
- Public routes use edge TLS.
- The guide warns learners not to enter confidential or customer-identifying
  information.
- Workshop outputs are illustrative and require human validation.
